# Image cards and social visuals

Read this when a requested Instagram/Facebook post needs a new visual, carousel card, or cover.

## Inputs

Confirm:

- destination platform and format
- exact headline/facts that may appear in the image
- active brand profile, colors, logo, fonts, and imagery rights
- whether the user wants a real photo, illustration, or typography card

Never invent a brand logo, customer result, product appearance, price, certification, or testimonial. Use only user-provided or authorized assets.

## Creation

- Prefer the installed image-generation capability when available and appropriate.
- If it is unavailable, create a deterministic vector/typography card only when the environment can render and visually verify the final raster image. Otherwise stop and ask the user for media.
- For an Instagram portrait feed card, default to a 4:5 canvas such as 1080 × 1350 unless the current UI or user requires another format.
- Keep important text and logos away from edges. Use a clear hierarchy, high contrast, and mobile-readable type.
- Keep card copy short; supporting explanation belongs in the caption.
- Export a platform-supported raster file such as PNG or JPEG and verify dimensions before upload.

## Approval and upload

Display the actual generated image to the user together with the caption and destination. Approval of text alone does not approve a materially different visual, and approval of a visual does not add another platform.

During Instagram crop, select the intended ratio (normally 4:5 for a 1080 × 1350 card) and visually confirm that no headline, logo, or footer is cut off. Preserve original colors unless the user asks for a filter.

If the platform presents an AI-content label, do not toggle it blindly. Inspect the current explanation and apply it when required for the actual content or when the user requests it.
